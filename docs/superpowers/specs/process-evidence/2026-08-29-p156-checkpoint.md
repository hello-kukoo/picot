### P1.7 supported implementation

`src-tauri/src/process_tree.rs` is the shared Pi process-tree supervisor used by both native `PiRpcBridge` and legacy `PiManager` paths. Unix uses an exact process-group identity check with `SIGTERM` deadline escalation to `SIGKILL`; Windows configures a Job Object with kill-on-close and has a bounded direct-child fallback. Child termination is followed by wait/reap, and attach failure rolls back the child.

## P1.6 implemented subset

- Native stop admission is exact-target and idempotent.
- The native stop trace is ordered as `AdmissionClosed → OperationsSettled → ProcessTreeTerminated → ProcessReaped → TemporaryResourcesCleaned → RuntimeUnregistered`.
- Native owner identity and workspace generation are carried from the existing owner registry for owner-scoped stop.
- Explicitly mounted Quick Chat temporary directories are deleted through the existing root, token, and symlink containment checks.
- Native owner destroy/app-exit hooks revoke owner-bound runtimes, ephemeral leases, temporary directories, and owner state.
- Workspace transition commit validates owner + transition generation, stops old-generation native runtimes, and cleans old-generation Side/Quick leases through existing registry authority.
- OAuth remains fail-closed: native capability is unsupported and no token cleanup is claimed.
